# 反刍打断 · 青少年"越想越累"自我调节工具

一个手机优先的静态站点（H5，可"添加到主屏幕"当 App 用），帮 12–18 岁的人做三件事：
**察觉自己在绕圈 → 用一个 1–3 分钟的动作打断 → 把"为什么"翻译成"下一步"。**

- 在线地址：<https://mtjvmysnk9-tech.github.io/fanzhua-mini/>
- 数据：全部存在你自己手机的 localStorage，**默认不联网、不上传、无第三方脚本、无统计**。
- 后端：不需要。阿里云方案是设计稿，见 [docs/BACKEND-ALIYUN.md](docs/BACKEND-ALIYUN.md)。

## 打开就能用

| 入口 | 干什么 |
|---|---|
| 今天 | 反刍强度 0–10 温度计 + 触发标签 + 写下脑子里那句原话 → 自动分流"在重复 / 可行动"，并推荐两张卡；下面挂一件今天的 5 分钟小事 |
| 打断 | 8 张卡：5-4-3-2-1 着陆、4-6 呼吸（带动画计时）、换机位第三人称重述、身体先动、离开这个位置、约"专门想"的时间、占住工作记忆、把"为什么"换成"下一步"。每张卡做完给前后分 |
| 记录 | 日志按词表规则自动分类（命中词当场显示，可手动改）；表达性书写 4 天；两周趋势图 |
| 自评 | 反刍风格自评 10 题，忧思 / 反省分开算、分开画；不是诊断 |
| 陪练 | 本地固定 5 步流程（说清事件 → 判重复 → 换机位 → 一个动作 → 停止信号）。**明说不是 AI、不理解你**，也不联网 |
| 我的 | 求助与 12356、家长/老师怎么说、数据导出导入清空、来源与局限 |

危机词（13 个，公开在来源页）在任何输入框命中时：不推荐工具卡、不继续问流程，直接换成求助卡。
命中判断是过敏感的——宁可多推一次求助，不赌漏报。

## 本地跑起来

没有构建步骤。三种方式任选：

1. 直接双击 `index.html`（Chrome/Edge 可以，Safari 对 `file://` 的 localStorage 有限制）；
2. 把整个文件夹拖进任意静态服务器；
3. 部署到 GitHub Pages（见下）。

## 部署

```bash
git init
git config user.name "<你的 GitHub 用户名>"
git config user.email "<用户名>@users.noreply.github.com"
git add -A && git commit -m "反刍打断 v1：静态站点 + 设计文档"
git remote add origin git@github.com:<用户名>/<仓库名>.git
git push -u origin master:main        # 本地默认 master，GitHub 默认 main
```

然后在仓库 **Settings → Pages** 选 `Deploy from a branch` / `main` / `/(root)`，保存。
一两分钟后访问 `https://<用户名>.github.io/<仓库名>/`。

**所有资源引用都是相对路径**，所以挂在 `/仓库名/` 子路径下也能正常工作；不要改成 `/assets/...`。

## 局限（请先读这段再给孩子用）

- 这是自我调节的辅助镜，**不是诊断、不是治疗、不是治疗师**；非医疗机构不得开展心理治疗。
- 卡片把有证据的干预路线压缩成 3 分钟动作，不等于等效于正式的心理治疗。
- 词表分流会误判，所以每一条都允许手动改。
- 出现自伤念头、连续两周起不来、成绩与人际断崖式下滑：直接找专业评估，别靠这个工具。
