# 反刍打断

帮 12–18 岁的人处理「越想越累」的移动端 H5 原型：0–10 强度温度计 + 写下脑子里那句原话，按词表分流成「在重复 / 可行动」，推一张 1–3 分钟就能做完的打断卡，再把「为什么」翻译成「下一步」。

线上地址（本仓库经 GitHub Pages 部署）：<https://mtjvmysnk9-tech.github.io/fanzhua-mini/>

## 分工

- **我做的**：提出需求（人群、场景、"要真的能点、每条都要有出处、不许做成占位演示"）、决定危机词命中时必须停下手不推工具卡、在浏览器里建仓并推送上线、逐页验收线上版本。
- **AI 做的**：设计思路文档、内容（8 张打断卡、RRS-10 教育版条目、分流词表、求助与家长页）、代码、部署。
- 内容不靠谁的权威：每条依据都摊在站点「我的 → 来源与局限」和 [docs/DESIGN.md](docs/DESIGN.md) 里，包括词表原文，任何人都能推翻判得不准的那一条。

## 结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 单页外壳 + 底部五个入口（今天 / 打断 / 记录 / 自评 / 我的），hash 路由 |
| `assets/js/data.js` | 内容层：卡片文案、量表条目、词表、来源——改文案只动这里 |
| `assets/js/engine.js` | 逻辑层：分流、危机识别、推荐、陪练状态机，全是纯函数 |
| `assets/js/app.js` | 视图层：表单、计时动画、趋势图、导入导出 |
| `assets/js/config.js` | 后端开关，`apiBase` 留空 = 纯本地 |
| `docs/` | 设计思路、阿里云方案与示例代码 |

无构建步骤、无依赖包、无第三方脚本，纯静态。

## 后端：方案写了，没部署

默认所有记录只存在浏览器 `localStorage`，页面不发任何网络请求——反刍的内容往往是一个孩子最不想被别人看到的那部分，默认写进云端等于让工具本身变成风险来源。

要接真人对话或趋势分析时走阿里云 FC + 百炼，接口契约、授权流程、数据最小化和成本账在 [docs/BACKEND-ALIYUN.md](docs/BACKEND-ALIYUN.md)，示例代码在 `aliyun-fc/`。填上 `config.js` 里的地址并手动打开上传开关才会联网。

## 数据说明

- 量表条目取自 Nolen-Hoeksema & Morrow (1991) 的 RRS 短形式条目池，二因子结构来自 Treynor 等 (2003)，中文措辞参考韩秀、杨宏飞 (2009)；**分级只看忧思那一半**，反省高不等于有病。
- 打断卡对应循证路线（着陆、延长呼气、自我抽离、担忧时间、行为激活、RFCBT），是压缩成 3 分钟的动作，不等于正式心理治疗。
- 热线号码来自国家卫健委关于 **12356** 全国统一心理援助热线的通知。
- 分流靠字符串包含匹配，会误判，所以每一条都允许手动改；这是**自评镜子，不是诊断**。

## 本地运行

直接双击 `index.html` 就能用（`localStorage` 在 `file://` 下同样可用）。想在手机上试，起一个静态服务即可：

```
python -m http.server 8000
```
