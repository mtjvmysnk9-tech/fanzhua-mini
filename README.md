# 反刍打断

帮 12–18 岁的人处理「越想越累」的移动端 H5 原型：0–10 强度温度计 + 写下脑子里那句原话，按词表分流成「在重复 / 可行动」，推一张 1–3 分钟就能做完的打断卡，再把「为什么」翻译成「下一步」。

线上地址（本仓库经 GitHub Pages 部署）：<https://mtjvmysnk9-tech.github.io/fanzhua-mini/>
正式站点（含真实上报）：<https://rumi-break-t3tamdheczu.qoder.zone/>

## 结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 单页外壳 + 底部五个入口（今天 / 打断 / 记录 / 自评 / 我的），hash 路由 |
| `admin.html` | 全站匿名汇总页，只读，不进底部导航 |
| `assets/js/data.js` | 内容层：卡片文案、量表条目、词表、来源——改文案只动这里 |
| `assets/js/engine.js` | 逻辑层：分流、危机识别、推荐、陪练状态机，全是纯函数 |
| `assets/js/app.js` | 视图层：表单、计时动画、趋势图、导入导出、上报队列 |
| `assets/js/config.js` | 后端开关：按域名决定 `apiBase` 与是否允许上传 |
| `functions/` | 正式后端的接口（校验 + 聚合），`routes.mjs` 纯业务、依赖注入 |
| `schema.sql` | 上报表结构，只走迁移 API 支持的 DDL 子集 |
| `dev/` | 本地一键复现：构建 + 起服务 + 38 条接口回归测试 |
| `docs/` | 设计思路、后端方案与合规清单 |

前端无构建步骤、无依赖包、无第三方脚本。

## 两个地址的差别

| | GitHub Pages | 正式站点 |
| --- | --- | --- |
| 页面 | 完全一样 | 完全一样 |
| `config.js` 判定 | `apiBase` 空 | `/functions/v1/app` |
| 联网请求 | **一个都不发** | 只在手动打开上报后发 |
| 全站趋势 / 汇总页 | 不显示 | 有 |
| 数据落在 | 只在你手机的 `localStorage` | 本机 + 云端匿名数字表 |

同一个包放到哪个域名上就自动长成哪个样子，靠的是 `assets/js/config.js` 里的域名判断，没有两份代码。

## 后端：匿名数字上报

默认关闭。要打开得自己在「我的 → 数据与隐私」里勾选，而且**只勾这一次，导入旧数据时会自动关掉**。

打开后上传的只有这些：

- 一条打分：日期、0–10 强度；
- 一次打断：日期、打断前后的分数、用了哪张卡的 id。

**不上传**：那句原话、任何文字、卡片标题、量表分数、危机词命中、姓名、精确时间（服务端只盖自己的时钟）。危机分流命中时前端直接跳过上报，一条都不发。

服务端再做三件事：字段白名单（多余字段丢弃，非白名单的 `kind` 整条拒收）、单次批量上限 50 条 / 64KB、以及**聚合门槛**——窗口内开启上报的设备不足 5 台时，只回一个总数，任何分组统计都清空，防止小样本反推出个人。原始行保留 30 天后删除。

接口契约、字段校验规则、为什么选这个而不是阿里云 FC，在 [docs/BACKEND-ALIYUN.md](docs/BACKEND-ALIYUN.md)；阿里云 FC + 百炼的示例代码仍在 `aliyun-fc/`，作为换平台的备选。

## 数据说明

- 量表条目取自 Nolen-Hoeksema & Morrow (1991) 的 RRS 短形式条目池，二因子结构来自 Treynor 等 (2003)，中文措辞参考韩秀、杨宏飞 (2009)；**分级只看忧思那一半**，反省高不等于有病。
- 打断卡对应循证路线（着陆、延长呼气、自我抽离、担忧时间、行为激活、RFCBT），是压缩成 3 分钟的动作，不等于正式心理治疗。
- 热线号码来自国家卫健委关于 **12356** 全国统一心理援助热线的通知。
- 分流靠字符串包含匹配，会误判，所以每一条都允许手动改；这是**自评镜子，不是诊断**。

## 本地运行

直接双击 `index.html` 就能用（`localStorage` 在 `file://` 下同样可用）。

想连后端一起跑（本机复现正式站点的接口和数据流）：

```
deno run --allow-read --allow-write dev/build.mjs   # 生成 dist/
deno run --allow-read --allow-net dev/server.mjs    # http://127.0.0.1:8787
deno run --allow-read --allow-net dev/test.mjs      # 38 条接口回归
```

地址写 `localhost` 时和正式站点一样允许上报，方便在本地验证整条链路。
